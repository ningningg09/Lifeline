# Lifeline: Personal health tracker for astronauts

Lifeline is a website to track astronaut health in space stations. 

There are interactive areas to input health information from your own trackers specific to the surrounding environment. Other interfaces are also incorporated into the website to track specific health issues and concerns. 


# Trackers and info requirements
- ECG measurements
- Blood pressure (cuff devices)
- DEXA scan machine
- MOFSET dosimeter


# Features
- Measuring severity of radiation levels. 
- Measuring cardiovascular health
- Tracking neurological health
	- Including neurological stresses
	- Mini reaction time game to test reaction time
- Measuring heart rate
- Measuring body temperature
- Tracking hydration
- Tracking sleep 
- Journal to track daily activities and state.
